## Request Parameters

<Tabs>
<TabItem value="required" label="Required" default>

- **optionSymbol** `string`

  The option symbol (as defined by the OCC) for the option you wish to lookup. Use the current OCC option symbol format. Historical options data starts in 2010, with the OCC symbol format change. Calculated Greeks start with the session of July 1, 2010 (see [Historical Greeks](#historical-greeks)).

</TabItem>
<TabItem value="optional" label="Optional">

- **date** `date`

  Use to lookup a historical end of day quote from a specific trading day. If no date is specified the quote will be the most current price available during market hours. When the market is closed the quote will be from the last trading day. Accepted date inputs: `ISO 8601`, `unix`, `spreadsheet`.

  :::info[Historical quotes include Greeks]
  On a request with `date`, `from` or `to`, the `iv`, `delta`, `gamma`, `theta` and `vega` columns are calculated by Market Data from each session's end-of-day quotes. See [Historical Greeks](#historical-greeks).
  :::

- **from** `date`

  Use to lookup a series of end of day quotes. From is the oldest (leftmost) date to return (inclusive). If from/to is not specified the quote will be the most current price available during market hours. When the market is closed the quote will be from the last trading day. Accepted date inputs: `ISO 8601`, `unix`, `spreadsheet`.

- **to** `date`

  Use to lookup a series of end of day quotes. To is the newest (rightmost) date to return (inclusive). If from/to is not specified the quote will be the most current price available during market hours. When the market is closed the quote will be from the last trading day. Accepted date inputs: `ISO 8601`, `unix`, `spreadsheet`.

- **model** `string`

  The pricing model of the calculated Greeks on a historical request (`date`, or `from` and `to`). Paid plans only (Starter, Trader, Quant, Prime and Commercial; not trials). A request with `model` on a free or trial plan, or without a token (also for an AAPL contract, the [demo symbol](/api/authentication#demo-the-api-with-no-authentication)), gets `402 Payment Required`, with `"errmsg":"The model parameter is only available for paying users."` Leave out `model` to get the default models.

  - `bsm`: Black-Scholes-Merton for every contract. It does not value early exercise.
  - `bjs`: Bjerksund-Stensland (1993) for American-style contracts.
  - `crr`: Cox-Ross-Rubinstein, a binomial tree, for American-style contracts.
  - `baw`: Barone-Adesi-Whaley for American-style contracts.
  - `default`: the default models (the same as no `model`).

  With `bjs`, `crr` or `baw`, European-style contracts still use Black-Scholes-Merton. Without `model`, American-style contracts use Bjerksund-Stensland and European-style contracts use Black-Scholes-Merton. The value is not case-sensitive, and long names also work (for example `blackscholesmerton`, `binomial`).

  `model` applies only to historical requests. On a current quote, a paid plan gets `400 Bad Request`:

  ```json
  {"s":"error","errmsg":"The 'model' parameter applies only to historical requests (date=, or from= and to=) without source=."}
  ```

  On a paid plan, an unknown model name is also a `400`, with `"errmsg":"Invalid model. Use one of: bsm, bjs, crr, baw."`

</TabItem>
</Tabs>

## Response Attributes

<Tabs>
<TabItem value="Success" label="Success" default>

- **s** `string`

  Status will always be `ok` when there is data for the quote requested.

- **optionSymbol** `array[string]`

  The option symbol according to OCC symbology.

- **underlying** `array[string]`

  The ticker symbol of the underlying security.

- **expiration** `array[number]`

  The option's settlement value time: the moment the price that decides the payout is fixed. It is 4:00 PM Eastern on the expiration date for stock options and PM-settled index options (such as SPXW), 9:30 AM Eastern for AM-settled index options (such as the monthly SPX), and 1:00 PM Eastern on an early-close day. It is not the last trading time. See [Option Expiration](/docs/api/dates-and-times#option-expiration). All timestamps use US Eastern Time (America/New_York). See [Response Timezone](/docs/api/dates-and-times#response-timezone) for details.

- **side** `array[string]`

  The response will be `call` or `put`.

- **strike** `array[number]`

  The exercise price of the option.

- **firstTraded** `array[date]`

  The date the option was first traded.

- **dte** `array[number]`

  The number of days until the option expires.

- **ask** `array[number]`

  The ask price.

- **askSize** `array[number]`

  The number of contracts offered at the ask price.

- **bid** `array[number]`

  The bid price.

- **bidSize** `array[number]`

  The number of contracts offered at the bid price.

- **mid** `array[number]`

  The midpoint price between the ask and the bid, also known as the mark price.

- **last** `array[number]`

  The last price negotiated for this option contract at the time of this quote.

- **volume** `array[number]`

  The number of contracts negotiated during the trading day at the time of this quote.

- **openInterest** `array[number]`

  The total number of contracts outstanding. Open interest is published once per trading day: it is calculated after the close and released at the start of the next session, and it does not change intraday. On a historical request (`date=D`, or a `from`/`to` series), this is therefore the figure settled out of the D−1 session and available before the open on D — unlike every other field in the row, which is as of the 16:00 ET `updated` timestamp. To get the open interest produced by trading on day D, request the next trading day.

- **underlyingPrice** `array[number]`

  The last price of the underlying security at the time of this quote.

- **inTheMoney** `array[booleans]`

  Specifies whether the option contract was in the money true or false at the time of this quote.

- **intrinsicValue** `array[number]`

  The instrinisc value of the option.

- **extrnisicValue** `array[number]`

  The extrinsic value of the option.

- **updated** `array[number]`

  The date and time of this quote snapshot. All timestamps use US Eastern Time (America/New_York). See [Response Timezone](/docs/api/dates-and-times#response-timezone) for details.

:::note[Greeks on historical requests]
On a request with `date`, `from` or `to`, `iv`, `delta`, `gamma`, `theta` and `vega` are calculated by Market Data from each session's end-of-day quotes. A value that cannot be calculated is `null`, never `0`. See [Historical Greeks](#historical-greeks).
:::

- **iv** `array[number]`

  The [implied volatility](https://www.investopedia.com/terms/i/iv.asp) of the option.

- **delta** `array[number]`

  The [delta](https://www.investopedia.com/terms/d/delta.asp) of the option.

- **gamma** `array[number]`

  The [gamma](https://www.investopedia.com/terms/g/gamma.asp) of the option.

- **theta** `array[number]`

  The [theta](https://www.investopedia.com/terms/t/theta.asp) of the option.

- **vega** `array[number]`

  The [vega](https://www.investopedia.com/terms/v/vega.asp) of the option.

</TabItem>
<TabItem value="NoData" label="No Data">

Returned when the request is valid, but **no quote data exists** for the requested symbol or time period.  
This response corresponds to an **HTTP 404 Not Found** status.

- **s** `string`  
  Will be `no_data`.

- **errmsg** `string`  
  A descriptive message explaining why no data is available.  
  For example:  
  - `"No option found. No option was found for this strike and expiration."`  
  This occurs when even though the option symbol format is valid, no real, tradable contract exists for the specified strike and expiration.

A `no_data` response may occur when:
- The market is closed (weekends or holidays)
- The symbol or option contract had no trading quotes on the requested date
- The contract had not begun trading yet
- No option exists for the requested strike and expiration

Even when the option symbol format is valid, the absence of a real, tradable contract or any quote data results in a `404` / `no_data` response.

</TabItem>

<TabItem value="Error" label="Error">

Returned when the request itself is invalid or cannot be processed.

- **s** `string`  
  Will be `error`.

- **errmsg** `string`  
  A human-readable description of the error.

These cases correspond to **HTTP 400 Bad Request**, such as:
- Invalid or malformed option symbol format
- Parameters that cannot be parsed
- Unsupported or invalid values

Use the HTTP status code—not just the `s` field—to distinguish between invalid input (`400`) and valid requests that simply have no data (`404` via `no_data`).

</TabItem>

## Historical Greeks

Market Data calculates the implied volatility and the Greeks of a historical request from the end-of-day quotes of that session:

1. **Option price:** the mid of the end-of-day bid and ask. The last trade price is not used.
2. **Underlying price:** the underlying price stored with the quote.
3. **Time to expiration:** from 4:00 PM Eastern on the session date to the contract's settlement value time, in calendar days divided by 365.
4. **Risk-free rate:** the risk-free rate curve of the session date, at the contract's expiration.
5. **Carry:** implied for each expiration from the chain's own call and put prices (put-call parity), not from a dividend calendar.
6. **Implied volatility:** the volatility at which the model price equals the mid. The model is Bjerksund-Stensland (1993) for American-style contracts and Black-Scholes-Merton for European-style contracts, or the [`model`](#request-parameters) that you name.
7. **Greeks:** delta, gamma, theta and vega at that implied volatility.

Each quote gets the values of its session's whole chain, so a quote has the same values in every request. A `from`/`to` series calculates each session separately.

**Units** (the same as on current quotes): `iv` is a decimal (`0.3012` is 30.12%). `delta` and `gamma` are per $1 of the underlying. `theta` is per calendar day. `vega` is per 1 volatility point (0.01 of `iv`). Values are rounded to 4 decimals.

**Null values.** A value that cannot be calculated is `null`: for example, a contract with no bid and no ask, an ask below the bid, or a mid that no volatility can reach. If the mid is at or below the lowest price that the model allows (for example, a deep in-the-money American put at its exercise value), `iv` is `null`, and with the default models the Greeks are the values at zero volatility. `rho` is not calculated.

**Coverage.** Calculated Greeks start with the session of July 1, 2010. Some sessions with known data faults return `null`.

## Usage Information

### Data Availability

The type of option quote data you receive depends on your user type and OPRA entitlement. This may include real-time data, 15-minute delayed data, or historical data, depending on the plan or access level. To get real-time options data, users need to sign the OPRA agreement. [Learn more about entitlements](/account/entitlements).

| User Type        | OPRA Entitlement | Data Type              |
|------------------|------------------|------------------------|
| Non-Professional | ✅               | Real-time              |
| Non-Professional | ❌               | 15-min delayed         |
| Professional     | Any              | Historical (1 day old) |
| Unknown          | Any              | Historical (1 day old) |


### Pricing

The cost of using the option quote API endpoint depends on the type of data you choose and your usage pattern. Here's a breakdown of the pricing:

| Data Type        | Cost Basis        | Credits Required per Unit |
|------------------|-------------------|---------------------------|
| Real-Time Data   | Per option symbol | 1 credit                  |
| 15m Delayed Data | Per option symbol | 1 credit                  |
| Historical Data  | Per 1000 quotes   | 1 credit                  |
