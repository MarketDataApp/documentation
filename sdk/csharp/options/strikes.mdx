Retrieve the strike prices listed for an underlying symbol, grouped by expiration date.

## Making Requests

Use `GetStrikesAsync` on the `Options` resource.

```csharp
Task<OptionsStrikesResponse> GetStrikesAsync(
    string underlying, DateOnly? date = null, DateOnly? expiration = null,
    MarketDataRequestOptions? options = null, CancellationToken cancellationToken = default)
Task<OptionsStrikesResponse> GetStrikesAsync(OptionsStrikesRequest request, ...)
```

### OptionsStrikesRequest

```csharp
new OptionsStrikesRequest(string underlying)
{
    Expiration = DateOnly,   // strikes for one expiration only
    Date = DateOnly          // strikes available as of this historical date
}
```

#### Returns

`OptionsStrikesResponse` wrapping a single `OptionStrikes` record — a dictionary of strike lists keyed by expiration date rather than a flat list:

```csharp
public sealed record OptionStrikes(
    DateTimeOffset? Updated,
    IReadOnlyDictionary<DateOnly, IReadOnlyList<decimal>> ByExpiration);
```

## Examples

```csharp
using MarketDataApp;

using var client = await MarketDataClient.CreateAsync();

var strikes = await client.Options.GetStrikesAsync("AAPL");
foreach (var (expiration, prices) in strikes.Values.ByExpiration)
{
    Console.WriteLine($"{expiration:yyyy-MM-dd}: {prices.Count} strikes from {prices[0]} to {prices[^1]}");
}
```

For CSV output, call `client.Options.GetStrikesCsvAsync(...)` and read `.Csv`. See [Settings](/sdk/csharp/settings#csv-output).
